# Knowledge base

Supporting knowledge for an audit: how the environment behaves, where things are, what a
dialog is actually doing. It exists so the rubrics can stay about **what makes an app pass**
while everything needed to *operate* the platform without misreading it lives here.

**This is reference, never the gate.** Nothing in these pages decides a verdict, adds a
requirement or excuses one. A page can tell you that an app's first-run credentials are
usually in the Tips dialog; only the protocol says whether credentials found there satisfy
the requirement. Where a page and a protocol disagree, **the protocol governs** — say so in
the report and carry on.
